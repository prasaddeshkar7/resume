# Prasad Deshkar Resume Website

Static GitHub Pages site.

## Files
- `index.html` — redesigned SEO-friendly site
- `Prasad_Deshkar_Senior_Software_Engineer_Resume.pdf` — resume PDF used by the download buttons
- `robots.txt` — crawler guidance
- `sitemap.xml` — sitemap for the public resume URL

All website download buttons use the browser's `download` attribute so the downloaded filename is:
`Prasad_Deshkar_Senior_Software_Engineer_Resume.pdf`

Upload these files to the `main` branch root of `prasaddeshkar7/resume` and keep GitHub Pages configured for the root.
